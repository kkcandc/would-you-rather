# Would You Rather

A pass-and-play living-room game for one shared screen. Two dare cards show up, somebody taps one, and the room has to actually do it before the buzzer.

Pick a card, actually do it before the buzzer, then pass the screen.

Names are optional. The deck has original dares only: physical challenges, silly voices, tiny performances, and a short board-game option if you have one nearby. About a third of the cards are silly-gross (imaginary bugs, mouth noises, shoe scores). They stay pretend. Nothing mean, nothing that makes a real mess, and nothing that asks you to spit on anybody.

Music, the drumroll, the buzzer, and the cheer are generated in the browser with the Web Audio API.

## Play locally

```bash
npm install
npm run dev
```

`npm run check` shuffles the deck and confirms dares are not paired when they need the same prop.
